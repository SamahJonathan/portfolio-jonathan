# Jonathan Samah — Portfolio

Data Engineer portfolio built with React 19, Framer Motion, and Tailwind CSS.

## Features

- ✨ Smooth animations with Framer Motion
- 🎨 Modern design with Tailwind CSS
- 📱 Fully responsive
- ⚡ Built with Vite for fast development
- 🚀 Ready to deploy on Vercel

## Projects Showcased

1. **ETL Pipeline Portfolio** — Odoo → BigQuery pipelines with Apache Airflow
2. **GCP Infrastructure as Code** — Terraform modules for Google Cloud
3. **AC Propiedades Full Stack** — Real estate system (PHP/Vue)
4. **CRM with AI** — Lead management with Claude API (Next.js)
